# 🛡️ Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting Security Invariants & Vulnerabilities

Security is the core priority of SorobanFlow. If you identify an issue affecting fund security, contract state synchronization, or streaming locks, please report responsibly.

**Please DO NOT submit public issues for security vulnerabilities.**
